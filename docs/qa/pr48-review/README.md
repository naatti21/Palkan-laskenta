# PR #48 – Compact Precision v2

Synteettiset kuvat. Sarakkeet vasemmalta: hyväksytty HTML-malli, PR #46 (78f6bdd), PR #48 ennen katselmointia (145fd40), korjattu PR #48 (86c6bb8). Prototyypin esimerkkisummat eroavat Beta-buildien yhteisestä testiaineistosta. Näyttö on 840 CSS-pikseliä korkea. Kuvien yläreunan otsikkokaista on vertailun selite.

Seuranta avautuu näytön yläreunaan. Kuukauden netto, viimeisin palkka, lähde, YTD, verokortin jäljellä oleva määrä ja ennuste näkyvät 320 ja 390 pikselissä. Tuonti, kalenteri ja ristiriita on kuvattu kyseisestä toiminnosta. Mittauksissa scrollTop ilmaisee vierityksen. Vuosiyhteenvedon ylimääräinen otsikko poistettiin; lisätiedot ja kaavio säilyvät. 390 px:ssä Seurannan korkeus lyheni 1114 → 1092 px. Asetusten tekninen tunniste on edelleen data, näkyvä nimi Asetukset.

V2:n Laskuri on lyhyt mallinäkymä. Betassa säilyvät koko laskuri ja osavalinta. PDF-tuonnissa ja ristiriidassa käytetään oikeita parserin ja päätöslogiikan näkymiä. Prototyypin kuukauden nettovaikutuksen sijaan Beta näyttää nimenomaisesti valitun laskelmaparin vaikutuksen. Fyysinen Android ja asennetun PWA:n päivitys: NOT RUN.
